# Password and Two-Factor Recovery

## Resetting your password
You can reset your password with a one-time password (OTP) sent to you by SMS. The OTP is valid for 5 minutes. If you enter it incorrectly 3 times, password reset is locked for 30 minutes and you can try again afterwards. Request the code only when you are ready to type it in, so it does not expire.

## App PIN
The app PIN is 6 digits long. If you enter the wrong PIN 5 times, the app is locked for 1 hour.

## Lost phone or changed number
If you have lost your phone or changed your mobile number and can no longer receive SMS codes, you can re-verify your identity with a photo of your national ID and a selfie. This check can take up to 24 hours, so start it as early as possible.

## Two-factor authentication
You can use two-factor authentication (2FA) by SMS or with an authenticator app. You also receive 8 single-use backup codes, and each code works only once. Store them somewhere safe and private. Nile Wallet staff never ask you for your OTP or backup codes.
